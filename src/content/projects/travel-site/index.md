# ✈️ Travel Site

O **Travel Site** é uma landing page moderna e responsiva desenvolvida para promover destinos turísticos e pacotes de viagem através de uma experiência visual elegante e envolvente.

O projeto foi criado com foco em design, usabilidade e conversão, apresentando uma interface inspirada em sites profissionais do setor de turismo, utilizando HTML, CSS e JavaScript para construir uma navegação fluida e adaptável a diferentes dispositivos.

## ✨ Funcionalidades

- Layout totalmente responsivo
- Navbar fixa com navegação fluida
- Hero section com destaque visual e CTA
- Galeria de destinos turísticos
- Cards de pacotes de viagem
- Sistema visual de avaliações e preços
- Seção de newsletter e inscrição
- Galeria de imagens inspiracionais
- Estrutura otimizada para experiência do usuário

## 🎨 Destaques visuais

O projeto foi desenvolvido com foco em estética moderna e experiência visual agradável, utilizando:

- Layout clean e contemporâneo
- Hierarquia visual bem definida
- Uso estratégico de imagens e tipografia
- Componentes reutilizáveis
- Responsividade para desktop e mobile
- Ícones vetoriais leves com Remix Icon

Além disso, toda a interface foi organizada para destacar os principais elementos de conversão, como chamadas para ação e apresentação de pacotes turísticos.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Remix Icon
- Google Fonts

## 🎯 Objetivo do projeto

Esse projeto foi desenvolvido como prática de construção de landing pages modernas, explorando conceitos de responsividade, design visual e organização de conteúdo voltado para marketing digital.

Durante o desenvolvimento, trabalhei conceitos importantes como:

- Estruturação semântica de páginas
- Construção de layouts responsivos
- Organização visual focada em conversão
- Manipulação básica de interatividade com JavaScript
- Criação de componentes reutilizáveis
- Uso de tipografia e imagens para reforço visual

Além de servir como exercício técnico, o Travel Site também funciona como modelo reutilizável para agências de turismo, páginas promocionais e aplicações focadas em apresentação visual de serviços e experiências.
