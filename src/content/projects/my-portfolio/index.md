# 💻 vdonoladev — Portfólio Pessoal

O **vdonoladev** é meu portfólio pessoal desenvolvido para apresentar meus projetos, habilidades e serviços como desenvolvedor front-end e back-end freelancer.

O projeto foi construído com foco em performance, experiência do usuário e design moderno, utilizando React e Tailwind CSS para criar uma interface responsiva, elegante e altamente personalizada. A proposta é transformar o portfólio em uma experiência visual que represente tanto minhas habilidades técnicas quanto meu estilo como desenvolvedor.

## ✨ Funcionalidades

- Interface moderna e responsiva
- Navegação fluida entre seções
- Design inspirado em ambientes de desenvolvimento
- Integração rápida com WhatsApp para contato
- Componentes reutilizáveis e organizados
- Blocos de código estilizados
- Animações suaves e microinterações
- Estrutura preparada para expansão futura

## 🎨 Destaques visuais

O visual do projeto foi pensado para transmitir profissionalismo e identidade própria, utilizando:

- Layout dark mode com estética futurista
- Gradientes e efeitos sutis de profundidade
- Transições suaves com Tailwind CSS
- Ícones modernos via Lucide React
- Tipografia equilibrada e foco em legibilidade
- Estrutura visual inspirada em IDEs e ambientes de código

Além disso, todas as seções foram planejadas para oferecer uma experiência intuitiva e agradável em diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

- React.js
- Tailwind CSS
- React Hooks
- Lucide React
- React Syntax Highlighter

## 🎯 Objetivo do projeto

Esse projeto foi criado para funcionar como minha principal presença digital profissional, centralizando informações sobre minhas habilidades, serviços e projetos desenvolvidos.

Durante o desenvolvimento, trabalhei conceitos importantes como:

- Construção de interfaces modernas com React
- Componentização e reutilização de código
- Responsividade com Tailwind CSS
- Gerenciamento de estado com Hooks
- Criação de experiências visuais focadas em UX/UI
- Organização escalável de aplicações front-end

Mais do que apenas um site pessoal, esse projeto representa minha identidade como desenvolvedor e a forma como aplico design, tecnologia e experiência do usuário em aplicações web modernas.
