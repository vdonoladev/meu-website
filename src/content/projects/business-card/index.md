# 👤 Business-Card

O **Business-Card** é um componente visual interativo desenvolvido com HTML e CSS puro, criado para representar perfis profissionais de forma moderna, elegante e responsiva.

O projeto simula um cartão de apresentação contendo foto, nome, cargo e botão de ação, explorando conceitos de layout, responsividade e microinterações visuais através de efeitos de hover e transições suaves.

## ✨ Funcionalidades

- Cartão de perfil com efeito interativo
- Imagem de perfil circular
- Exibição de nome e função profissional
- Botão de ação customizável
- Efeito de hover com zoom e sombra
- Layout responsivo para diferentes dispositivos
- Design minimalista e reutilizável

## 🎨 Destaques visuais

O projeto foi construído com foco em simplicidade e experiência visual, utilizando:

- Transições suaves em CSS
- Efeitos de profundidade com box-shadow
- Escala dinâmica no hover
- Estrutura visual limpa e moderna
- Responsividade com media queries

Além disso, o componente foi pensado para ser facilmente adaptado em portfólios, páginas institucionais, landing pages ou seções de equipes.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts

## 🎯 Objetivo do projeto

Esse projeto foi desenvolvido como prática de construção de componentes reutilizáveis no front-end, trabalhando conceitos fundamentais de estilização, organização visual e responsividade sem utilização de frameworks.

Durante o desenvolvimento, explorei conceitos como:

- Estruturação semântica de componentes
- Estilização modular com CSS
- Microinterações com hover e transições
- Responsividade para múltiplos dispositivos
- Construção de layouts minimalistas

Além de servir como exercício técnico, o Business-Card também funciona como componente reutilizável para aplicações web modernas que precisem de blocos de apresentação visual elegantes e responsivos.
