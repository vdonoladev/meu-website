# 💳 c6Bank

O **c6Bank** é uma landing page moderna e responsiva inspirada na identidade visual de bancos digitais contemporâneos, com foco em experiência do usuário, animações fluidas e organização visual sofisticada.

O projeto foi desenvolvido utilizando React, SASS e JavaScript, explorando conceitos de motion design, performance e arquitetura de estilos escalável através da metodologia BEM.

## ✨ Funcionalidades

- Layout totalmente responsivo
- Animações suaves durante o scroll
- Estrutura moderna inspirada em fintechs
- Motion design focado em experiência visual
- Organização escalável de estilos com BEM
- Páginas estruturadas para navegação dinâmica
- Performance otimizada e carregamento leve
- Estrutura preparada para SEO

## 🎨 Destaques visuais

O visual do projeto foi construído para transmitir modernidade, tecnologia e fluidez, utilizando:

- Animações com AOS JS
- Transições suaves entre elementos
- Hierarquia visual organizada
- Componentes reutilizáveis em React
- Layout inspirado em interfaces de bancos digitais
- Uso avançado de SASS para modularização de estilos

Além disso, toda a interface foi desenvolvida pensando em responsividade e adaptação perfeita entre desktop, tablet e dispositivos móveis.

## 🛠️ Tecnologias utilizadas

- React.js
- JavaScript
- HTML5
- CSS3
- SASS
- AOS JS

## 🎯 Objetivo do projeto

Esse projeto foi desenvolvido como prática avançada de front-end moderno, com foco em criação de interfaces profissionais, motion design e organização escalável de código.

Durante o desenvolvimento, trabalhei conceitos importantes como:

- Componentização com React
- Estruturação de CSS utilizando metodologia BEM
- Criação de animações e microinterações
- Organização visual e hierarquia de conteúdo
- Responsividade avançada
- Otimização de performance e SEO

Além do aprendizado técnico, o projeto também serviu como exercício de construção de interfaces inspiradas em produtos reais do mercado financeiro, buscando equilíbrio entre estética, usabilidade e performance.
