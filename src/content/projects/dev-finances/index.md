# 💰 dev.finance$

O **dev.finance$** é uma aplicação web de controle financeiro pessoal criada com foco em simplicidade, organização e praticidade. A ideia do projeto é permitir o registro de entradas e saídas financeiras de forma intuitiva, exibindo automaticamente o saldo total e o histórico completo das transações.

Desenvolvido durante a **Maratona Discover da Rocketseat**, esse projeto foi uma ótima oportunidade para aprofundar conhecimentos em **HTML, CSS e JavaScript**, trabalhando conceitos importantes como manipulação de DOM, responsividade e persistência de dados com LocalStorage.

## ✨ Funcionalidades

- Registro de entradas e saídas financeiras
- Cálculo automático do saldo total
- Histórico completo de transações
- Exclusão individual de registros
- Persistência de dados com LocalStorage
- Interface responsiva para desktop e mobile

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
- Google Fonts

## 🎯 Objetivo do projeto

Além de funcionar como uma ferramenta simples de organização financeira, o projeto também serviu como prática para desenvolvimento front-end, com foco em construção de interfaces acessíveis, limpas e funcionais utilizando apenas tecnologias web nativas.

## 🔗 Destaques técnicos

Durante o desenvolvimento, trabalhei conceitos como:

- Estruturação semântica com HTML5
- Manipulação dinâmica da interface via JavaScript
- Armazenamento local de dados
- Responsividade com CSS
- Organização de código front-end sem frameworks

Esse projeto marcou uma etapa importante na minha evolução como desenvolvedor, principalmente no entendimento de como transformar lógica de programação em uma experiência visual e interativa.
