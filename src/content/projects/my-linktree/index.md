# 🌐 My Linktree

O **My Linktree** é uma página de links personalizada desenvolvida com HTML, CSS e JavaScript puro, criada para centralizar redes sociais, projetos e conteúdos em uma interface moderna, responsiva e visualmente interativa.

Inspirado no conceito de páginas estilo Linktree, o projeto busca oferecer uma alternativa mais customizável e com identidade própria, utilizando animações, efeitos visuais e uma experiência mais dinâmica sem depender de frameworks pesados.

## ✨ Funcionalidades

- Página centralizadora de links e redes sociais
- Fundo animado com partículas interativas
- Ícones vetoriais leves e modernos
- Layout responsivo para desktop e mobile
- Transições entre seções de conteúdo
- Área de destaque com vídeo incorporado
- Estrutura simples e facilmente customizável

## 🎨 Destaques visuais

O projeto foi desenvolvido com foco em estética minimalista e experiência visual moderna, utilizando:

- Efeitos animados com Particles.js
- Ícones SVG via Feather Icons
- Microinterações com JavaScript
- Layout clean e responsivo
- Transições suaves entre conteúdos

Além disso, toda a estrutura foi pensada para facilitar personalizações rápidas de identidade visual, links e informações pessoais.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- Particles.js
- Feather Icons

## 🎯 Objetivo do projeto

Esse projeto foi criado como prática de desenvolvimento front-end moderno, explorando conceitos de animação, responsividade e manipulação de interface utilizando apenas tecnologias web nativas.

Durante o desenvolvimento, trabalhei conceitos como:

- Estruturação semântica de páginas
- Manipulação dinâmica de elementos com JavaScript
- Criação de interfaces minimalistas
- Responsividade com CSS
- Integração de bibliotecas leves para efeitos visuais

Além de funcionar como exercício técnico, o My Linktree também serve como solução reutilizável para criadores de conteúdo, desenvolvedores e profissionais que desejam centralizar seus links em uma página elegante e personalizada.
