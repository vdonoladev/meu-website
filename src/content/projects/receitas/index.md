# 🍽️ Receitas – Pamonha

O **Receitas** é uma aplicação web simples e responsiva desenvolvida para apresentar uma receita tradicional brasileira de forma moderna, interativa e acessível.

O projeto une culinária e desenvolvimento front-end em uma interface leve e intuitiva, permitindo que o usuário visualize ingredientes, acompanhe o modo de preparo e ajuste dinamicamente a quantidade de porções da receita.

## ✨ Funcionalidades

- Exibição completa da receita de pamonha
- Ajuste dinâmico do número de porções
- Interface responsiva para desktop e mobile
- Estrutura organizada de ingredientes e preparo
- Design limpo com foco em legibilidade
- Interações simples utilizando JavaScript

## 🎨 Destaques do projeto

A proposta visual do projeto foi criar uma experiência agradável e direta, valorizando a leitura da receita e a usabilidade da interface.

Durante o desenvolvimento, trabalhei conceitos como:

- Responsividade com CSS
- Manipulação dinâmica de elementos no DOM
- Atualização interativa de informações
- Estruturação semântica com HTML5
- Organização visual focada em experiência do usuário

Além disso, o projeto foi pensado para ser facilmente expandido para múltiplas receitas futuramente.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES6)
- GitHub Pages

## 🎯 Objetivo do projeto

Esse projeto foi desenvolvido como prática de front-end utilizando tecnologias web nativas, explorando conceitos de interatividade, responsividade e construção de interfaces funcionais sem frameworks.

Além do aprendizado técnico, o projeto também busca trazer um elemento cultural brasileiro para dentro do desenvolvimento web, mostrando como experiências simples podem se tornar aplicações elegantes e intuitivas.

O Receitas representa um exercício de construção de interfaces leves, acessíveis e focadas em usabilidade.
