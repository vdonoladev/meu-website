# 📚 dev-journey-log

O **dev-journey-log** é meu repositório pessoal de estudos e evolução em desenvolvimento de software. Mais do que apenas armazenar exercícios e anotações, ele funciona como um diário técnico vivo, documentando minha jornada de aprendizado de forma prática, organizada e contínua.

O projeto reúne cursos, desafios, experimentos, exercícios resolvidos, projetos práticos e materiais de referência, organizados por tecnologia, linguagem e plataforma. Cada commit representa uma nova etapa de aprendizado, servindo tanto como histórico de evolução quanto como base de consulta para revisões futuras.

## 🚀 O que o projeto reúne

- Exercícios e desafios de programação
- Estudos de frontend, backend e banco de dados
- Projetos desenvolvidos durante cursos e bootcamps
- Anotações técnicas organizadas por tema
- Materiais de referência rápida para diversas linguagens
- Roadmaps pessoais de aprendizado

## 🛠️ Tecnologias e áreas estudadas

O repositório abrange uma variedade de tecnologias e conceitos, incluindo:

- HTML, CSS e JavaScript
- TypeScript e ReactJS
- Node.js, Flask e Django
- PHP e Python
- SQL e modelagem de dados
- Git, Bash, Vim e TMUX
- APIs REST
- Responsividade e UX
- Arquitetura de Sistemas
- Metodologias Ágeis (SCRUM)

## 🎯 Objetivo do projeto

O principal objetivo do **dev-journey-log** é registrar de forma transparente minha evolução como desenvolvedor, consolidando conhecimento através da prática constante.

Além de funcionar como uma central de estudos, o projeto também demonstra minha organização, consistência e comprometimento com aprendizado contínuo, servindo como uma visão real da minha trajetória na programação.

## 💡 Destaques

- Estrutura organizada por tecnologias e plataformas
- Registro contínuo de progresso e aprendizado
- Grande variedade de conteúdos práticos
- Repositório em constante evolução
- Mistura de teoria, prática e documentação pessoal

Esse projeto representa não apenas o que já aprendi, mas também o caminho que continuo construindo diariamente no desenvolvimento de software.
